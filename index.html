About this project

Corner Store is a single-page storefront built for COMP 3612 (Web Development) at Mount Royal University. Every view (home, categories, browsing with filters, product details and the cart) lives in one HTML page and is swapped in with JavaScript.

Technologies

  • HTML5 & CSS3 (grid, flexbox, custom properties)
  • Vanilla JavaScript (ES modules), no libraries
  • Fetch API + DummyJSON product API
  • localStorage for the product cache and the cart
  • Hosted on GitHub Pages
